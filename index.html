Typing Pattern Collection

This page requires you to key in the password 100 times over one week: 20 times per session, 5 sessions, each on a different day.
This captures how your typing changes over the week. Type the password below exactly, press Enter, and repeat until you reach 20. Then press Submit session and come back on another day.

  • Use your own username, and the same one every session.
  • The password is the same for everyone. The R is a capital: hold Shift for it.
  • If you make a mistake, that attempt is not counted. Just type it again.

Only your username, the session dates and the key timings (how long each key is held and the gaps between keys) are recorded. Use a physical keyboard, and the same device each session if you can.
